
# IPL Data Analysis Project

## Project Title
IPL Data Analysis and Performance Analytics Dashboard

## Objective

The objective of this project is to analyze Indian Premier League (IPL) match and player data to uncover meaningful insights related to team performance, player performance, match outcomes, batting trends, bowling trends, venue statistics, toss decisions, and season-wise performance.

The project aims to transform raw IPL data into actionable sports and business insights using Python-based data analysis and visualization techniques, followed by the development of an interactive Power BI dashboard.

---

## Dataset Description

The dataset contains ball-by-ball and match-level IPL data, including information such as:

- Match ID
- Season
- Match Date
- City
- Venue
- Team1 and Team2
- Toss Winner
- Toss Decision
- Match Winner
- Player of the Match
- Batting Team
- Bowling Team
- Batsman
- Bowler
- Runs Scored
- Extra Runs
- Total Runs
- Wickets
- Overs and Balls

The dataset was cleaned and transformed before analysis to ensure data quality and consistency.

## Data Cleaning & Preparation

The following data preparation steps were performed:

- Imported and loaded IPL dataset
- Examined dataset structure and dimensions
- Checked data types
- Identified missing values
- Removed duplicate records
- Standardized team names
- Validated categorical fields
- Converted date columns into proper date format
- Verified cleaned dataset for consistency

These preprocessing steps ensured that the dataset was suitable for analysis and dashboard development.
